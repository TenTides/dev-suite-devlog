# Dev Suite dev log

Dated articles from building Dev Suite, a governance harness for AI coding agents.

Live at **https://tentides.github.io/dev-suite-devlog/**

- `posts/`: the articles, one `.mdx` file each
- `site/`: the website (Vite + React), published to GitHub Pages by `.github/workflows/pages.yml`

```
cd site
npm install
npm run dev
```
